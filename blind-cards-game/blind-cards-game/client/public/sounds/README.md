Poné acá tu archivo `life-lost.mp3` (el sonido que se reproduce cuando un jugador
pierde una vida). Mientras no exista, el juego usa automáticamente un sonido
sintetizado de reemplazo.

Importante: no incluyas música con copyright (bandas sonoras de anime, canciones
comerciales, etc.) si vas a subir este repositorio a un lugar público — usá un
sonido propio, grabado por vos, o de un banco de audio libre de derechos.
